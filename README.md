## The pitch

> We deliver terabytes by carrier pigeon: a USB strapped to a bird crosses town faster than your upload, and the bird never buffers, so studios pay per gigabyte flown.

## How it runs

`main.py` (Python 3.13, standard library only) writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else. It checks the line first: a single line, non-empty, at most 200 characters — the same gate the sealed scorer applies.
